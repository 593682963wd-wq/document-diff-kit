# 文档内容树、修订差异与证据工作台

作者：Wangyuan · 2026-10-29

本项目源码采用 MIT 许可证，见 LICENSE；第三方依赖仍适用各自上游许可。

## 可用能力

- 提取既有DOCX修订表解析、数据模型、差异算法、渲染及反读校验；文本新增/删除/修改、嵌套表格、图片和附录保留。
- 人工字段修改、来源哈希、同输入输出路径拒绝；差异片段红色加粗及下划线/删除线，结果为可编辑DOCX。
- 显式角色别名匹配、最近标题继承和文本替换；每条保留原文与段落锚点，均待人工复核。
- 显式风险关键词匹配、精确引文起止位置、人工意见和中性风险表导出；不内置制度。
- DOCX压缩/路径/外部关系/宏与XML实体检查；不启动LibreOffice或系统转换器。

## 运行

Python 3.11+。依赖仅为标准库，或 requirements.txt 明确列出的开源解析库。程序默认不联网；安装依赖时由包管理器下载。

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -B cli.py demo
python3 -B cli.py demo --output demo-output
python3 -B cli.py run example.json --output demo-output
python3 -B -m unittest discover -s tests -v
```

演示数据从零生成；默认临时目录会在命令结束时释放。需要保留文件或数据库时必须指定 --output，输入与输出目录应由使用者自行控制。JSON输出到标准输出，参数错误返回非零状态。

## 输入与输出

动作：`revision`、`clauses`、`paragraphs`、`risks`、`export`。每个动作参数名称对应核心文件中的同名函数/方法签名，公共接口有类型标注及中文说明。通用调用格式是 action 与 args；目录、收集模块另接受 tools/events/contract 等顶层显式合同。

```json
{
  "action": "clauses",
  "args": {
    "paragraphs": [
      {
        "id": "p1",
        "text": "资料组应核对记录。"
      }
    ],
    "aliases": [
      "资料组"
    ],
    "replacements": {
      "资料组": "审阅角色"
    }
  }
}
```

仅接受DOCX；需要结构为修订前/后列的输入表，完整文档之间自动整篇对齐不在此版本。嵌套表/图片作为内容块保留，不逐像素或逐表格单元作语义差异。EMF/WMF尽可能保留绘图XML，不调用转换器；复杂Office视觉一致性尚未人工逐页确认。paragraphs接口只读正文段落，职责条款表格须先人工明确文本。所有文件来自调用方明确路径。

## 保留边界

真实手册/部门档案、公司专项安全培训/教育规则、原排版样板、外部模型/Office转换程序与Web编辑器均未包含。

只保留通用流程与算法；这是经过提取/重构的独立工具或组件集合，并不声称完整迁移原应用、原业务质量或生产验收。源码来源、哈希与原入口映射保存在本地私有审计台账，不随此目录分发。

## 验证

tests/仅使用合成数据与临时文件，覆盖主流程、空/缺失、身份冲突和关键异常；cli.py demo可独立复现完整示例。未运行真实业务数据、联网/正式发送、原系统回归或生产部署。本项目为CLI/库，不包含Web UI。

附加动作 `pdf` 使用显式文件 `path`，在有限超时子进程中提取PDF文字层，保留页码与 `empty_text_pages`；不执行OCR、不保证阅读顺序或版面正确。默认5MB、100页、20万字符、10秒；Linux另有地址空间上限，macOS只验证超时/CPU与输入输出预算。返回始终待人工复核。`risk_summary` 参数为 `rows`、`dimensions`（ID到显示名）、`severity_order`（从低到高）；无匹配项目的严重度为空，不伪造“低风险”。

`pdf_pair_diff`/`pdf_group_diff`补充原章节差异算法：显式新旧PDF或目录，保留段落差异块、最近字段、旧文档纯删除章节、增加/删除文件及逐文件错误。章节/字段/噪声正则通过`rules`传入，原业务规则和检查清单全部删除；默认只识别`## 标题`，中文短标签仅启发式。表达式是操作者配置。空文字页拒绝当作完整比较，不比较图形或执行OCR。`diff_excel`用通用三列表和显式检查项导出，文本按字面量保存，拒绝覆盖已有文件。
